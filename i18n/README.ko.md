# Hackintosh Sequoia 복구 연구실

Dell OptiPlex 7050 듀얼 부팅 개발 장비를 위한 비공개 운영 자료입니다.
Monterey 12.7.6은 복구 시스템으로 보존하고 Sequoia 15.7.7은 개발
시스템으로 사용합니다.

검증된 결과:

- OpenCore 1.0.7
- Intel HD530을 Kaby Lake `0x5912`로 인식
- 1536 MB 동적 VRAM 및 Metal 3
- OCLP 그래픽 루트 패치가 없는 봉인된 Sequoia 시스템 볼륨
- Monterey와 Sequoia가 APFS 여유 공간을 동적으로 공유

전체 업그레이드 기록, 복구 절차, 업데이트 정책과 출처는
[영문 README](../README.md)에 있습니다. EFI, 장비 식별자, 자격 증명,
Apple 소프트웨어는 포함하지 않습니다.
