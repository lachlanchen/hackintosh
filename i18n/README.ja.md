# Hackintosh Sequoia リカバリーラボ

Dell OptiPlex 7050 デュアルブート開発機のための非公開運用資料です。
Monterey 12.7.6 を復旧用として維持し、Sequoia 15.7.7 を開発環境として
使用します。

検証済みの状態:

- OpenCore 1.0.7
- Intel HD530 を Kaby Lake `0x5912` として認識
- 1536 MB 動的 VRAM、Metal 3
- OCLP グラフィックスルートパッチを使わない Sequoia のシール済みシステム
- Monterey と Sequoia が APFS の空き容量を動的に共有

完全な作業履歴、復旧手順、更新ポリシー、出典は
[英語版 README](../README.md) を参照してください。EFI、端末固有 ID、
認証情報、Apple ソフトウェアは含みません。
