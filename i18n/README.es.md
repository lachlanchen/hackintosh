# Laboratorio de recuperación Hackintosh Sequoia

Referencia privada para una estación Dell OptiPlex 7050 con arranque dual.
Monterey 12.7.6 se conserva como sistema de recuperación y Sequoia 15.7.7 es
el sistema de desarrollo.

Resultado verificado:

- OpenCore 1.0.7
- Intel HD530 presentada como Kaby Lake `0x5912`
- 1536 MB de VRAM dinámica y Metal 3
- volumen de sistema Sequoia sellado, sin parche gráfico raíz de OCLP
- espacio APFS compartido dinámicamente por Monterey y Sequoia

El [README en inglés](../README.md) contiene la cronología completa, el manual
de recuperación, la política de actualizaciones y las fuentes. El repositorio
no incluye EFI, identidad de máquina, credenciales ni software de Apple.
