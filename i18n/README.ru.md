# Лаборатория восстановления Hackintosh Sequoia

Закрытая эксплуатационная документация для двухсистемной рабочей станции Dell
OptiPlex 7050. Monterey 12.7.6 сохранена как система восстановления, а
Sequoia 15.7.7 используется для разработки.

Проверенный результат:

- OpenCore 1.0.7
- Intel HD530 представлена как Kaby Lake `0x5912`
- 1536 МБ динамической видеопамяти и Metal 3
- запечатанный системный том Sequoia без корневого графического патча OCLP
- динамически общий контейнер APFS для Monterey и Sequoia

Полная хронология, инструкция по восстановлению, политика обновлений и источники
находятся в [английском README](../README.md). Репозиторий не содержит EFI,
идентификаторы компьютера, учетные данные или программное обеспечение Apple.
